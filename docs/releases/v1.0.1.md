## 中文

公开版本 **v1.0.1** 对应应用内显示的构建 **1.1.2**。本次更新修正了五个场景的机械动作、macOS Dock 图标大小，以及窗口可见时偶发的动画停顿。[源码提交 da8807c](https://github.com/NoctisWang528/RelayAtelier/commit/da8807c126d1c95ed03db8c16a526465dfa7ae8e)

- **Westworld** 的跨线两端都固定在内圈轨道上。转盘加速或换向时，焊点和弯折段随所属扇区一起转动。
- **Factory** 重绘了机械臂的肩架、肘部销轴和夹爪。抓起、搬运和放下货箱时，可以看清夹爪与箱体的交接。
- **Slots 和 Roulette** 的旋钮、轮辐和齿纹随机构转动，外壳和投影的位置保持稳定。
- **Chips** 移除了牌面顶端的放射线。出牌和落桌动作、牌面上的工具状态仍然可见。
- **桌面窗口** 调整了双色飞轮图标的透明边距，使它在 macOS Dock 中与相邻图标大小接近。窗口仍然可见时，即使收到延迟的隐藏通知也会继续播放；最小化时会暂停绘制。

**安装。** 将对应平台的 ZIP 完整解压到可写目录。macOS arm64 用户可将 `Relay Atelier.app` 移入“应用程序”。Windows x64 用户从解压目录运行 `Relay Atelier.exe`。

**验证。** 80 项自动化测试、28 项 Chromium 界面检查、10 项 macOS 打包窗口检查通过。Mac 包在 Apple Silicon 真机上运行，采用临时签名，未经 Apple 公证。Windows 包未签名，在 CrossOver 中运行了 Westworld、Factory、Chips、Slots、Roulette 的 Demo 并检查了 Hook 面板。原生 Windows 尚待验证。

## English

Public release **v1.0.1** appears in the app as build **1.1.2**. This update fixes motion in five scenes, adjusts the macOS Dock icon size, and fixes an intermittent animation freeze while the window is visible. [Source commit da8807c](https://github.com/NoctisWang528/RelayAtelier/commit/da8807c126d1c95ed03db8c16a526465dfa7ae8e)

- **Westworld** anchors both ends of each crossover wire to the inner tracks. The pads and bends turn with their sector as the dial accelerates or reverses.
- **Factory** has a redrawn shoulder mount, elbow pin, and gripper. The contact between the jaws and the crate is easier to follow through pickup, transport, and release.
- **Slots and Roulette** keep the housings and cast shadows fixed while the knobs, spokes, and gear teeth turn.
- **Chips** removes the rays above the card. Dealing, landing, and tool status updates remain visible on the card.
- **Desktop window** adds transparent padding around the two-tone flywheel so it sits at a similar size to neighboring macOS Dock icons. A delayed hide notification now allows playback to continue if the window is still visible. Minimizing the window pauses drawing.

**Installation.** Extract the entire ZIP to a writable folder. On macOS arm64, move `Relay Atelier.app` to Applications. On Windows x64, run `Relay Atelier.exe` from the extracted folder.

**Verification.** All 80 automated tests, 28 Chromium UI checks, and 10 packaged macOS window checks passed. The Mac app ran on Apple Silicon hardware and is ad hoc signed and unnotarized. The unsigned Windows package ran the Westworld, Factory, Chips, Slots, and Roulette demos and displayed the hooks panel under CrossOver. Native Windows verification is pending.
