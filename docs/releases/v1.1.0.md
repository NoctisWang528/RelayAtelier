## 中文

Relay Atelier v1.1.0 对应应用构建 1.2.0。这次新增 18 个 Agent 来源，现在可以在本机观察 21 个来源的工具调用。[源码提交 815b35c](https://github.com/NoctisWang528/RelayAtelier/commit/815b35c130a7d622de242a5f44b6cf4040470351)

- **新增来源**包括 Gemini CLI、GitHub Copilot CLI、Qwen Code、Kimi CLI / Code、Pi、Oh My Pi、OmO Native / SenPi、OpenClaw、Factory Droid、CodeBuddy Code、WorkBuddy、DeepSeek Harness、Cline、Reasonix、MiMo Code / Desktop、Kilo Code、Cherry Studio Agents 和 Proma。原有的 Codex、Claude Code 和 OpenCode 继续支持。[默认位置和会话格式](https://github.com/NoctisWang528/RelayAtelier/blob/v1.1.0/docs/SOURCES.md#agent-session-locations)
- **按 Agent 管理监听。** 在“本地来源 → Agent 监听设置”选择 Agent，可单独启停监听，并在默认位置之外添加多个目录。保存后立即生效，重启后会保留设置。
- **桌面版自动检查更新。** 启动时及持续运行期间每 24 小时检查 GitHub 正式发行版。有新版时可从提示打开发行页下载，也可在“本地来源”手动检查。

选择与操作系统及处理器匹配的 ZIP，完整解压到可写目录。Mac 打开 `Relay Atelier.app`，Windows 运行 `Relay Atelier.exe`。

**验证范围。** 103 项自动化测试和 28 项浏览器界面检查通过。macOS ARM64 正式包在 Apple Silicon 真机通过 10 项桌面窗口检查，x64 包在 Rosetta 下通过 23 项来源与更新测试。Windows x64 包已在 CrossOver 中运行并验证了逐 Agent 开关、自定义 Windows 路径和读取工具事件。四个压缩包均已检查可执行文件架构、归档完整性、内嵌版本和应用源码。macOS 包使用本地临时签名，未经过 Apple 公证。Windows 包未签名，原生 Windows 真机运行仍待验证。

## English

Relay Atelier v1.1.0 is application build 1.2.0. It adds 18 agent sources, bringing local tool-call monitoring to 21 sources. [Source commit 815b35c](https://github.com/NoctisWang528/RelayAtelier/commit/815b35c130a7d622de242a5f44b6cf4040470351)

- **New sources** include Gemini CLI, GitHub Copilot CLI, Qwen Code, Kimi CLI / Code, Pi, Oh My Pi, OmO Native / SenPi, OpenClaw, Factory Droid, CodeBuddy Code, WorkBuddy, DeepSeek Harness, Cline, Reasonix, MiMo Code / Desktop, Kilo Code, Cherry Studio Agents and Proma. Codex, Claude Code and OpenCode remain supported. [Default locations and supported formats](https://github.com/NoctisWang528/RelayAtelier/blob/v1.1.0/docs/SOURCES.md#agent-session-locations)
- **Per-agent monitoring.** Open the local sources panel to enable or disable an agent and add session directories alongside its defaults. Saved changes take effect immediately and persist across restarts.
- **Desktop update checks.** The app checks GitHub for a stable release at startup and every 24 hours while running. An update prompt opens the release page for download. A manual check is available in the local sources panel.

Download the ZIP for your operating system and processor and extract it to a writable folder. Open `Relay Atelier.app` on macOS or run `Relay Atelier.exe` on Windows.

**Verification.** All 103 automated tests and 28 browser UI checks passed. The macOS ARM64 release passed 10 desktop window checks on Apple Silicon. The x64 build passed 23 source and update tests under Rosetta. The Windows x64 package ran under CrossOver, where we enabled a source, selected a custom Windows directory and read a tool event. All four archives were checked for processor architecture, archive integrity, embedded version and application source. The macOS packages are ad hoc signed and unnotarized. The Windows packages are unsigned. Native Windows testing is pending.
