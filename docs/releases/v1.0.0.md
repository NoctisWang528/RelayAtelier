## 中文

Relay Atelier 首次公开发行。在原来的终端或客户端中使用 Codex、Claude Code 或 OpenCode，Relay Atelier 会在独立窗口里把工具调用画成机械动作。打开 **Demo → Factory** 即可试看；切到 **Live** 可观察本机会话，**Replay** 可回放历史。

- **八种场景**共享同一份会话状态。切换 Westworld、Loom、Factory、Chips、Rhythm、Slots、Roulette 或 DataFlow，可以从不同角度观察同一次调用。
- **Loom** 的工具铭牌会随窗口宽度分行。多个工具共用织轴时，悬停可以展开完整名称。**Factory** 的货箱在两个面上印有工具图记，正面风扇的叶片围绕固定轴承转动。
- **可选 Hook** 可在桌面窗口的“本地来源 → Agent Hooks”中安装或移除。工具状态来自本机会话记录。

将对应平台的 ZIP 完整解压到可写目录。**macOS arm64** 打开 `Relay Atelier.app`，**Windows x64** 打开 `Relay Atelier.exe`。附件含 SHA-256 校验文件。

**验证范围。** 80 项自动化测试、28 项 Chromium 界面检查和 9 项 macOS 打包窗口检查通过。Mac 包已在 Apple Silicon 真机运行，使用临时签名，未经 Apple 公证。Windows 包未签名，已在 CrossOver 中运行 Factory、Loom 和 Hook 面板，原生 Windows 待验证。

**版本对应。** 公开版本为 **v1.0.0**，应用内的本地构建版本为 **1.1.1**。两份下载包均来自提交 `58cdcbf`。

## English

This is the first public release of Relay Atelier. Keep using Codex, Claude Code, or OpenCode in your usual terminal or client and watch tool calls drive a separate desktop window. Open **Demo → Factory** for a first look, switch to **Live** to follow local sessions, or use **Replay** to revisit a session.

- **Eight scenes** share the same session state. Follow one call across Westworld, Loom, Factory, Chips, Rhythm, Slots, Roulette, and DataFlow.
- **Loom** arranges tool nameplates in rows to fit the window. Hover over a shared spool to see all its tool names. **Factory** stamps tool symbols on two faces of each crate. Its front fan turns around a fixed bearing.
- **Optional hooks** can be installed or removed from the desktop window’s local sources panel under **Agent Hooks**. Tool status comes from local session records.

Extract the entire ZIP to a writable folder. On **macOS arm64**, open `Relay Atelier.app`. On **Windows x64**, open `Relay Atelier.exe`. SHA-256 checksums are included with the downloads.

**Verification.** All 80 automated tests, 28 Chromium UI checks, and 9 packaged macOS window checks passed. The Mac app ran on Apple Silicon hardware and is ad hoc signed and unnotarized. The Windows executable is unsigned. Factory, Loom, and the hooks panel were exercised under CrossOver. Native Windows testing is pending.

**Version mapping.** The public release is **v1.0.0**. The app reports local build **1.1.1**. Both downloads come from the same [source commit](https://github.com/NoctisWang528/RelayAtelier/commit/58cdcbf15eda16cdd224a28e6947b855f0533fcb).
