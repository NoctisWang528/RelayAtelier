# Relay Atelier 使用手册

## 安装与第一次观察

在包含 `package.json` 的目录运行 `npm ci`。这会按锁文件安装当前平台的开发依赖。首次执行 npm start 时，Electron 如缺少本平台的二进制文件，会先下载。从另一台机器复制项目时，在目标机重新安装依赖。安装后可用以下命令核实环境。

```sh
node --version
npm --version
node -e "console.log(typeof require('node:sqlite').DatabaseSync)"
npm start
```

SQLite 检查应输出 `function`。在独立窗口右下角打开“本地来源”，查看各来源的状态和最后事件时间。选择“全部会话”可同时观察多个 Agent。首次读入的历史可以填充计数和 Loom 铭牌，织梭会在收到可演出的事件后出发。

打开 **本地来源 → Agent 监听设置**，选择要配置的 Agent，勾选或取消“启用此 Agent”。在“自定义会话目录”中每行填一个完整路径，桌面版也可点击“选择目录…”多选。点击“保存设置”立即生效，重启后仍会保留。清空自定义目录并保存即可恢复默认位置。桌面版与浏览器版各自保存设置。[各 Agent 的默认位置](SOURCES.md#agent-session-locations)

桌面版启动后和持续运行期间每 24 小时向 GitHub 检查一次正式发行版。发现新版会提示打开发行页，可在其中选择对应平台的压缩包。“本地来源”里的“检查应用更新…”可随时重试。网络中断时仍可继续观察本地会话。

常规观察使用只读轮询。若希望缩短工具调用后的刷新等待，在桌面窗口打开 **本地来源 → Agent Hooks**，查看对应 Agent 的目标文件，点击安装。要撤销时，在同一行点击移除。浏览器版可读取已安装 Hook 的唤醒信号，安装与移除在桌面窗口完成。[支持的宿主、信任要求和恢复方法](HOOKS.md)

| 模式 | 数据来自哪里 | 合适的观察方式 |
| --- | --- | --- |
| Live | 本机正在监听的会话，另含启动时读到的近期历史 | 先查看最近真实事件，再在自己原来的 Agent 客户端正常工作。没有新增事件时画面可保持安静。 |
| Replay | 当前已保留的历史，按所选会话筛选 | 选择播放速度或重新播放。原始长间隔最多保留 1.4 秒，再按速度缩放。 |
| Demo | 内置生成的模拟工具事件 | 无需真实会话，可查看失败、并发、等候和不同场景。切回 Live 时恢复真实状态。 |

## 控制窗口

| 操作 | 作用 |
| --- | --- |
| 数字键 1 到 8，或顶部场景按钮 | 按界面顺序切换场景，继续观察共享的会话状态。 |
| 空格 | 暂停或继续演出。在暂停期间，来源监听仍继续。 |
| F | 进入或退出专注视图，为场景留出更多空间。 |
| 底部太阳按钮 | 在瓷白和石墨外观之间切换，DataFlow 也跟随该设置。 |
| 底部图钉 | 切换桌面窗口置顶。浏览器标签页由浏览器管理。 |
| Loom 铭牌上悬停 | 铭牌直接显示操作名；悬停可读完整限定名，以及共享这组经线的所有工具。 |

场景与主题在当前窗口使用的本地存储中记忆。最小化或隐藏窗口会停止绘制场景。空闲时绘图目标约 12 fps，实际帧率取决于窗口尺寸和机器负载。

## 本机数据位置

下表中的 `~` 表示运行观察器的用户主目录。默认路径来自当前实现。使用其他配置目录的客户端可以在开发接入时显式构造 `SourceHub({roots})`，目前界面提供会话筛选。

| 内容 | 位置或保存方式 |
| --- | --- |
| Codex 会话 | `~/.codex/sessions/` 下的 JSONL；若设置 `CODEX_HOME`，从该目录的 `sessions/` 读取 |
| Claude Code 会话 | `~/.claude/projects/` 下的 JSONL，包含受支持的子代理记录；可用 `CLAUDE_CONFIG_DIR` 指定配置根目录 |
| OpenCode 数据库 | 默认 `~/.local/share/opencode/opencode.db`，以只读模式打开；若设置 `XDG_DATA_HOME`，使用其中的 `opencode/opencode.db` |
| 源码桌面窗口资料 | 项目内 `.runtime/desktop/`，测试窗口另用 `.runtime/desktop-verification/`；可用 `RELAY_DATA_DIR` 指定独立目录 |
| 浏览器模式 | 浏览器保存界面设置和本地访问 Cookie。终端打印的启动链接限本机使用。 |
| 本地验收附件 | `evidence/` 和 `output/`。真实来源的截图可能含文件名和会话标识。可分享的固定样例在 [examples](../examples/)。 |

## 常见问题

| 现象 | 检查和处理 |
| --- | --- |
| 双击后看到旧界面 | 已有安装包时，旧启动器会优先选包；从项目根目录运行 `npm start` 或双击 `start-source.command`。 |
| 源码启动器提示找不到 Electron | 先在当前目录执行 `npm ci` 和 `npm start`，让 Electron 完成首次启动。Mac 源码启动器直接使用项目内已下载的二进制文件。 |
| Live 有计数，转盘却停着 | 查看最近真实事件时间、会话筛选和暂停状态。读到历史后可以切 Replay 检查该批数据。 |
| 某来源显示缺失 | 在来源详情中查看类型和诊断，核对上表路径以及客户端是否已落盘。客户端使用其他路径时，当前界面不会自动猜测。 |
| 等了很久仍显示未知 | 查看工具流中的状态。日志缺少明确结果时保留未知；进行中或等待超过五分钟，界面会推断超时未知。 |
| 调用数比画面里的货箱多 | 查看“队列 / 已折叠”。繁忙时调度器合并或舍弃部分演出，计数来自保留窗口中的逻辑调用。 |
| 浏览器显示 401 或旧标签页失效 | 打开本次 `npm run web` 打印的完整链接，以取得本次进程的本地访问 Cookie。关闭服务用 Ctrl+C。 |
| 复现失败时需要反馈信息 | 记录操作系统、Node 版本、模式、场景、窗口尺寸和最短复现步骤。优先附 Demo 或合成 Replay 截图。 |

早先为观察原版而单独安装的可选 OpenCode 插件，其来源、哈希和可逆移除方式见[历史安装记录](HOOK-RESEARCH.md)。运行或退出 Relay Atelier 无需执行该移除脚本。
